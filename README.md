# ApexPlanet Task 3 — Advanced Styling and JavaScript

## Files
- `index.html` — page structure and content
- `style.css` — complete responsive styling
- `script.js` — quiz, navigation and API functionality

## Task requirements covered
1. Responsive design using CSS Grid, Flexbox, media queries and `clamp()`.
2. Interactive JavaScript quiz with:
   - 8 frontend questions
   - Multiple-choice options
   - Instant answer feedback
   - Score tracking
   - Progress bar
   - Restart / Try Again
   - Final result message
3. Public API integration:
   - Open-Meteo geocoding + weather API
   - JokeAPI programming joke endpoint
   - `fetch()`, async/await, JSON parsing and error handling

## How to run
Open `index.html` in a modern browser.

For the most reliable API behavior, use VS Code Live Server or another local development server.
